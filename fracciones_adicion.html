Suma y Resta de Fracciones Algebraicas

10 Ejercicios resueltos paso a paso con simplificación

Ejercicio 1 Mismo Denominador Monomio
$$\frac{3x + 1}{2x} + \frac{x - 5}{2x}$$
Paso 1: Como las fracciones tienen el mismo denominador ($2x$), sumamos los numeradores en una sola fracción:
$$\frac{(3x + 1) + (x - 5)}{2x}$$
Paso 2: Agrupamos y reducimos términos semejantes en el numerador:
$$\frac{4x - 4}{2x}$$
Paso 3: Factorizamos el numerador sacando el factor común $2$ para simplificar con el denominador:
$$\frac{2(2x - 2)}{2x} = \frac{2x - 2}{x}$$
Resultado: $$\frac{2x - 2}{x} \quad \text{ó} \quad 2 - \frac{2}{x}$$
Ejercicio 2 Resta con Denominador Común Binomio
$$\frac{x^2}{x - 3} - \frac{9}{x - 3}$$
Paso 1: Combinamos los numeradores sobre el denominador común ($x - 3$):
$$\frac{x^2 - 9}{x - 3}$$
Paso 2: Factorizamos la diferencia de cuadrados en el numerador ($x^2 - 9 = (x - 3)(x + 3)$):
$$\frac{(x - 3)(x + 3)}{x - 3}$$
Paso 3: Cancelamos el factor común $(x - 3)$:
Resultado: $$x + 3$$
Ejercicio 3 Denominadores Monomios Distintos
$$\frac{2}{3x} + \frac{5}{2x^2}$$
Paso 1: Hallamos el $\text{mcm}$ de los denominadores $3x$ y $2x^2$, que es $6x^2$.
Paso 2: Convertimos cada fracción a su forma equivalente con denominador $6x^2$:
$$\frac{2 \cdot (2x)}{3x \cdot (2x)} + \frac{5 \cdot 3}{2x^2 \cdot 3} = \frac{4x}{6x^2} + \frac{15}{6x^2}$$
Paso 3: Sumamos los numeradores:
Resultado: $$\frac{4x + 15}{6x^2}$$
Ejercicio 4 Denominadores Lineales Primos Entre Sí
$$\frac{3}{x + 2} - \frac{2}{x - 1}$$
Paso 1: El $\text{mcm}$ de los denominadores es el producto $(x + 2)(x - 1)$.
Paso 2: Expresamos ambas fracciones sobre el denominador común:
$$\frac{3(x - 1) - 2(x + 2)}{(x + 2)(x - 1)}$$
Paso 3: Aplicamos la propiedad distributiva en el numerador:
$$\frac{3x - 3 - 2x - 4}{(x + 2)(x - 1)}$$
Paso 4: Reducimos términos semejantes:
Resultado: $$\frac{x - 7}{(x + 2)(x - 1)} \quad \text{ó} \quad \frac{x - 7}{x^2 + x - 2}$$
Ejercicio 5 Factor Común en el Denominador
$$\frac{x}{x^2 - 4x} + \frac{2}{x - 4}$$
Paso 1: Factorizamos el primer denominador sacando factor común $x$: $x^2 - 4x = x(x - 4)$.
$$\frac{x}{x(x - 4)} + \frac{2}{x - 4}$$
Paso 2: Simplificamos la primera fracción cancelando $x$ ($x \neq 0$):
$$\frac{1}{x - 4} + \frac{2}{x - 4}$$
Paso 3: Sumamos las fracciones con el mismo denominador:
Resultado: $$\frac{3}{x - 4}$$
Ejercicio 6 Diferencia de Cuadrados
$$\frac{1}{x - 5} - \frac{10}{x^2 - 25}$$
Paso 1: Factorizamos el segundo denominador: $x^2 - 25 = (x - 5)(x + 5)$.
$$\frac{1}{x - 5} - \frac{10}{(x - 5)(x + 5)}$$
Paso 2: El $\text{mcm}$ es $(x - 5)(x + 5)$. Homogeneizamos la primera fracción multiplicando por $(x + 5)$:
$$\frac{1 \cdot (x + 5) - 10}{(x - 5)(x + 5)} = \frac{x + 5 - 10}{(x - 5)(x + 5)} = \frac{x - 5}{(x - 5)(x + 5)}$$
Paso 3: Cancelamos el factor común $(x - 5)$:
Resultado: $$\frac{1}{x + 5}$$
Ejercicio 7 Trinomio $x^2 + bx + c$
$$\frac{2}{x + 3} + \frac{x - 1}{x^2 + 5x + 6}$$
Paso 1: Factorizamos el trinomio $x^2 + 5x + 6 = (x + 2)(x + 3)$.
$$\frac{2}{x + 3} + \frac{x - 1}{(x + 2)(x + 3)}$$
Paso 2: El $\text{mcm}$ es $(x + 2)(x + 3)$. Llevamos a denominador común:
$$\frac{2(x + 2) + (x - 1)}{(x + 2)(x + 3)}$$
Paso 3: Expandimos y reducimos el numerador:
$$\frac{2x + 4 + x - 1}{(x + 2)(x + 3)} = \frac{3x + 3}{(x + 2)(x + 3)}$$
Paso 4: Factorizamos el numerador sacando el factor $3$:
Resultado: $$\frac{3(x + 1)}{(x + 2)(x + 3)}$$
Ejercicio 8 Entero Menos Fracción Algebraica
$$x - \frac{x^2 - 4}{x + 2}$$
Método Directo por Factorización: Factorizamos el numerador de la fracción: $x^2 - 4 = (x - 2)(x + 2)$.
$$x - \frac{(x - 2)(x + 2)}{x + 2}$$
Paso 2: Cancelamos el término $(x + 2)$ para $x \neq -2$:
$$x - (x - 2)$$
Paso 3: Eliminamos los paréntesis cambiando el signo:
$$x - x + 2$$
Resultado: $$2$$
Ejercicio 9 Suma y Resta de 3 Fracciones
$$\frac{1}{x} + \frac{2}{x^2} - \frac{1}{x + 1}$$
Paso 1: Determinamos el $\text{mcm}$ de los denominadores $x$, $x^2$ y $(x + 1)$, el cual es $x^2(x + 1)$.
Paso 2: Adaptamos los numeradores al nuevo denominador común:
$$\frac{1 \cdot x(x + 1) + 2 \cdot (x + 1) - 1 \cdot x^2}{x^2(x + 1)}$$
Paso 3: Desarrollamos los productos en el numerador:
$$\frac{(x^2 + x) + (2x + 2) - x^2}{x^2(x + 1)}$$
Paso 4: Simplificamos los términos $x^2 - x^2 = 0$ y sumamos los términos lineales:
Resultado: $$\frac{3x + 2}{x^2(x + 1)} \quad \text{ó} \quad \frac{3x + 2}{x^3 + x^2}$$
Ejercicio 10 Cambio de Signo en el Denominador
$$\frac{x + 2}{x - 3} + \frac{4}{3 - x}$$
Paso 1: Observamos que el segundo denominador $(3 - x)$ es el opuesto de $(x - 3)$, es decir, $3 - x = -(x - 3)$.
Paso 2: Cambiamos el signo de la segunda fracción:
$$\frac{x + 2}{x - 3} - \frac{4}{x - 3}$$
Paso 3: Ahora que comparten el mismo denominador, restamos los numeradores:
$$\frac{(x + 2) - 4}{x - 3} = \frac{x - 2}{x - 3}$$
Resultado: $$\frac{x - 2}{x - 3}$$
