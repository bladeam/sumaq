BAD 402 - Unidad III

El Lenguaje SQL

DDL, DML, Consultas Avanzadas, Joins y Subconsultas

🎯 Objetivo de la Unidad

Dominar el lenguaje estándar universal de Bases de Datos Relacionales (Structured Query Language) para definir, consultar y modificar datos.

💡 ¿Qué es SQL? Es el idioma que entienden casi todos los motores de bases de datos del mundo (PostgreSQL, MySQL, SQL Server, Oracle).
Unidad III - Introducción

1. Estructura y Sublenguajes de SQL

DDL (Data Definition Language)

Crea, altera y elimina la estructura de tablas y bases de datos.

CREATE, ALTER, DROP

DML (Data Manipulation Language)

Manipula los registros guardados en las tablas.

SELECT, INSERT, UPDATE, DELETE

Unidad III - DDL

2. Creación de Tablas (CREATE TABLE)

Permite definir una tabla con sus columnas, tipos de datos y restricciones:

CREATE TABLE estudiante ( ci INT PRIMARY KEY, nombre VARCHAR(50) NOT NULL, email VARCHAR(100) UNIQUE, edad INT CHECK (edad >= 17) );
Unidad III - DDL

3. Modificación y Borrado de Estructuras

ALTER TABLE

Agrega o modifica columnas en una tabla ya existente.

ALTER TABLE cliente ADD teléfono VARCHAR(15);

DROP TABLE

Elimina permanentemente la tabla y todos sus datos.

DROP TABLE pedido;

Unidad III - DML

4. Inserción de Datos (INSERT INTO)

Permite agregar nuevas filas a una tabla existente:

INSERT INTO estudiante (ci, nombre, email, edad) VALUES (884123, 'María López', 'maria@mail.com', 20);
Nota: Los textos y fechas se colocan siempre entre comillas simples ('...').
Unidad III - DML

5. Actualización de Datos (UPDATE)

Modifica valores en registros existentes.

UPDATE estudiante SET edad = 21 WHERE ci = 884123;

⚠️ ¡Precaución con WHERE!

Si ejecutas UPDATE estudiante SET edad = 21; sin la cláusula WHERE, cambiarás la edad de TODOS los estudiantes en la base de datos.

Unidad III - DML

6. Eliminación de Datos (DELETE)

Elimina filas específicas de una tabla:

DELETE FROM estudiante WHERE ci = 884123;
❓ ¿Cuál es la diferencia entre DELETE y DROP?
• DELETE borra filas pero conserva la tabla vacía.
• DROP borra los datos Y la estructura de la tabla por completo.
Unidad III - Consultas

7. Consulta Básica (SELECT - FROM)

Muestra información almacenada en las tablas:

-- Ver todos los campos de todos los productos SELECT * FROM producto; -- Ver solo el nombre y precio SELECT nombre, precio FROM producto;
Unidad III - Consultas

8. Filtrado de Datos (WHERE)

Aplica condiciones lógicas para filtrar los resultados:

SELECT nombre, precio FROM producto WHERE precio > 100 AND stock > 0;
Operadores: =, <>, >, <, >=, <=
Lógicos: AND, OR, NOT
Unidad III - Consultas

9. Ordenamiento de Resultados (ORDER BY)

Ordena el resultado final de forma ascendente o descendente:

SELECT nombre, precio FROM producto ORDER BY precio DESC;
• ASC: Ascendente (A-Z, 0-9) [Por defecto]
• DESC: Descendente (Z-A, 9-0)
Unidad III - Funciones

10. Funciones de Agregación

Realizan cálculos matemáticos sobre un conjunto de filas y devuelven un solo valor:

COUNT(*)
Cuenta el número de filas.
SUM(precio)
Suma los valores.
AVG(precio)
Calcula el promedio.
SELECT COUNT(*) AS total_clientes, AVG(edad) AS promedio_edad FROM estudiante;
Unidad III - Consultas

11. Agrupamiento de Datos (GROUP BY)

Agrupa filas que tienen los mismos valores en columnas especificadas para aplicar cálculos por grupo:

SELECT carrera, COUNT(*) AS total_alumnos FROM estudiante GROUP BY carrera;
Resultado: Muestra cuántos alumnos hay inscritos en cada carrera distinta.
Unidad III - Consultas

12. Filtrado de Grupos (HAVING)

WHERE vs. HAVING

• WHERE filtra filas INDIVIDUALES antes de agrupar.
• HAVING filtra GRUPOS después de aplicar GROUP BY.

SELECT carrera, COUNT(*) FROM estudiante GROUP BY carrera HAVING COUNT(*) > 50;
Unidad III - Joins

13. Combinación de Tablas (INNER JOIN)

Une filas de dos o más tablas en función de una columna relacionada (FK = PK):

SELECT e.nombre, c.nombre_carrera FROM estudiante e INNER JOIN carrera c ON e.carrera_id = c.id;
Muestra solo los estudiantes que tienen una carrera válida asignada.
Unidad III - Joins

14. Combinaciones Externas (LEFT / RIGHT JOIN)

LEFT JOIN

Devuelve TODAS las filas de la tabla izquierda, aunque no tengan coincidencia en la derecha.

RIGHT JOIN

Devuelve TODAS las filas de la tabla derecha, aunque no coincidan en la izquierda.

SELECT c.nombre, p.id_pedido FROM cliente c LEFT JOIN pedido p ON c.ci = p.cliente_ci;
Unidad III - Avanzado

15. Subconsultas (Subqueries)

Una consulta dentro de otra consulta en la cláusula WHERE o FROM:

-- Obtener productos más caros que el precio promedio SELECT nombre, precio FROM producto WHERE precio > (SELECT AVG(precio) FROM producto);
Unidad III - Vistas

16. Vistas (VIEWS)

Tabla Virtual

Una vista es una consulta SQL guardada como objeto en la base de datos que se puede consultar como si fuera una tabla real.

CREATE VIEW v_alumnos_sistemas AS SELECT ci, nombre FROM estudiante WHERE carrera = 'Sistemas';
Unidad III - Seguridad

17. Control de Acceso (DCL)

Comandos para gestionar permisos de seguridad a los usuarios:

GRANT

Otorga permisos de lectura o escritura.

GRANT SELECT ON producto TO usuario1;

REVOKE

Quita permisos otorgados anteriormente.

REVOKE INSERT ON producto FROM usuario1;

Unidad III - Práctica

18. Ejemplo Completo Integrado

Consulta compleja integrando JOIN, WHERE, GROUP BY y ORDER BY:

SELECT c.nombre, COUNT(p.id_pedido) AS total_compras FROM cliente c INNER JOIN pedido p ON c.ci = p.cliente_ci WHERE p.fecha >= '2026-01-01' GROUP BY c.nombre HAVING COUNT(p.id_pedido) >= 3 ORDER BY total_compras DESC;

19. Conclusiones de la Unidad III

SQL es el lenguaje indiscutible para interactuar con BDs relacionales.

2. Poder de Consulta
