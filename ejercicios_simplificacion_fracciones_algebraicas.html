10 Ejercicios de Simplificación de Fracciones Algebraicas

Guía práctica con soluciones paso a paso utilizando técnicas de factorización y simplificación.

Ejercicio 1 Factor común monomio
$$\frac{12a^3b^2}{18a^2b^4}$$
Paso 1: Simplificar los coeficientes numéricos dividiendo entre el máximo común divisor ($6$). $$\frac{12 \div 6}{18 \div 6} = \frac{2}{3}$$
Paso 2: Aplicar las leyes de los exponentes para las variables ($\frac{x^m}{x^n} = x^{m-n}$ o restar exponentes en la posición donde esté el mayor exponente). $$\text{Para } a: \frac{a^3}{a^2} = a^{3-2} = a$$ $$\text{Para } b: \frac{b^2}{b^4} = \frac{1}{b^{4-2}} = \frac{1}{b^2}$$
$$\text{Resultado final: } \frac{2a}{3b^2}$$
Ejercicio 2 Factor común polinomio
$$\frac{4x + 12}{8x + 24}$$
Paso 1: Extraer el factor común tanto del numerador como del denominador. $$\text{Numerador: } 4x + 12 = 4(x + 3)$$ $$\text{Denominador: } 8x + 24 = 8(x + 3)$$
Paso 2: Reescribir la fracción y cancelar los factores comunes binómicos. $$\frac{4(x + 3)}{8(x + 3)} = \frac{4}{8}$$
Paso 3: Simplificar la fracción numérica resultante. $$\frac{4}{8} = \frac{1}{2}$$
$$\text{Resultado final: } \frac{1}{2}$$
Ejercicio 3 Diferencia de cuadrados
$$\frac{x^2 - 9}{x^2 + 6x + 9}$$
Paso 1: Factorizar el numerador usando diferencia de cuadrados ($a^2 - b^2 = (a-b)(a+b)$). $$x^2 - 9 = (x - 3)(x + 3)$$
Paso 2: Factorizar el denominador reconociendo un trinomio cuadrado perfecto ($a^2 + 2ab + b^2 = (a+b)^2$). $$x^2 + 6x + 9 = (x + 3)^2 = (x + 3)(x + 3)$$
Paso 3: Cancelar los factores comunes del numerador y denominador. $$\frac{(x - 3)(x + 3)}{(x + 3)(x + 3)} = \frac{x - 3}{x + 3}$$
$$\text{Resultado final: } \frac{x - 3}{x + 3}$$
Ejercicio 4 Trinomio de la forma $x^2 + bx + c$
$$\frac{x^2 - 5x + 6}{x^2 - 4}$$
Paso 1: Factorizar el numerador buscando dos números que multiplicados den $6$ y sumados den $-5$ (los números son $-2$ y $-3$). $$x^2 - 5x + 6 = (x - 2)(x - 3)$$
Paso 2: Factorizar el denominador mediante diferencia de cuadrados. $$x^2 - 4 = (x - 2)(x + 2)$$
Paso 3: Cancelar el factor común $(x - 2)$. $$\frac{(x - 2)(x - 3)}{(x - 2)(x + 2)} = \frac{x - 3}{x + 2}$$
$$\text{Resultado final: } \frac{x - 3}{x + 2}$$
Ejercicio 5 Factor opuesto o cambio de signo
$$\frac{2x - 6}{9 - x^2}$$
Paso 1: Extraer el factor común en el numerador. $$2x - 6 = 2(x - 3)$$
Paso 2: Factorizar la diferencia de cuadrados en el denominador. $$9 - x^2 = (3 - x)(3 + x)$$
Paso 3: Notar que $(x - 3) = -(3 - x)$. Multiplicar por $-1$ para poder simplificar. $$\frac{2(x - 3)}{(3 - x)(3 + x)} = \frac{-2(3 - x)}{(3 - x)(3 + x)}$$
Paso 4: Cancelar el factor $(3 - x)$. $$\frac{-2}{3 + x} \quad \text{o} \quad -\frac{2}{x + 3}$$
$$\text{Resultado final: } -\frac{2}{x + 3}$$
Ejercicio 6 Suma o diferencia de cubos
$$\frac{x^3 - 8}{x^2 + 2x + 4}$$
Paso 1: Aplicar la fórmula de diferencia de cubos en el numerador: $a^3 - b^3 = (a - b)(a^2 + ab + b^2)$. $$\text{Aquí } a = x \text{ y } b = 2:$$ $$x^3 - 8 = (x - 2)(x^2 + 2x + 4)$$
Paso 2: Reescribir la fracción. $$\frac{(x - 2)(x^2 + 2x + 4)}{x^2 + 2x + 4}$$
Paso 3: Cancelar el trinomio $(x^2 + 2x + 4)$ que aparece en ambos términos. $$x - 2$$
$$\text{Resultado final: } x - 2$$
Ejercicio 7 Trinomio de la forma $ax^2 + bx + c$
$$\frac{2x^2 + 5x - 3}{4x^2 - 1}$$
Paso 1: Factorizar el numerador mediante descomposición o aspa simple: $$2x^2 + 5x - 3 = (2x - 1)(x + 3)$$
Paso 2: Factorizar el denominador utilizando diferencia de cuadrados. $$4x^2 - 1 = (2x - 1)(2x + 1)$$
Paso 3: Cancelar el binomio común $(2x - 1)$. $$\frac{(2x - 1)(x + 3)}{(2x - 1)(2x + 1)} = \frac{x + 3}{2x + 1}$$
$$\text{Resultado final: } \frac{x + 3}{2x + 1}$$
Ejercicio 8 Factorización por agrupación de términos
$$\frac{ax + bx - ay - by}{a^2 - b^2}$$
Paso 1: Factorizar el numerador agrupando de dos en dos términos. $$ax + bx - ay - by = x(a + b) - y(a + b) = (a + b)(x - y)$$
Paso 2: Factorizar la diferencia de cuadrados en el denominador. $$a^2 - b^2 = (a + b)(a - b)$$
Paso 3: Cancelar el factor común $(a + b)$. $$\frac{(a + b)(x - y)}{(a + b)(a - b)} = \frac{x - y}{a - b}$$
$$\text{Resultado final: } \frac{x - y}{a - b}$$
Ejercicio 9 Factorización compuesta (múltiples pasos)
$$\frac{3x^3 - 12x}{x^2 - 4x + 4}$$
Paso 1: En el numerador, extraer primero el factor común monomio $3x$ y luego aplicar diferencia de cuadrados. $$3x^3 - 12x = 3x(x^2 - 4) = 3x(x - 2)(x + 2)$$
Paso 2: Factorizar el denominador (trinomio cuadrado perfecto). $$x^2 - 4x + 4 = (x - 2)^2 = (x - 2)(x - 2)$$
Paso 3: Cancelar un factor $(x - 2)$ tanto del numerador como del denominador. $$\frac{3x(x - 2)(x + 2)}{(x - 2)(x - 2)} = \frac{3x(x + 2)}{x - 2}$$
$$\text{Resultado final: } \frac{3x(x + 2)}{x - 2} \quad \text{o} \quad \frac{3x^2 + 6x}{x - 2}$$
Ejercicio 10 Diferencia de cubos y trinomios mixtos
$$\frac{a^3 + 27}{a^2 - 3a + 9}$$
Paso 1: Factorizar la suma de cubos del numerador utilizando la identidad: $x^3 + y^3 = (x + y)(x^2 - xy + y^2)$. $$\text{Donde } x = a \text{ e } y = 3:$$ $$a^3 + 27 = (a + 3)(a^2 - 3a + 9)$$
Paso 2: Escribir la relación con el denominador original. $$\frac{(a + 3)(a^2 - 3a + 9)}{a^2 - 3a + 9}$$
Paso 3: Cancelar el factor irreducible del trinomio $(a^2 - 3a + 9)$. $$a + 3$$
$$\text{Resultado final: } a + 3$$
